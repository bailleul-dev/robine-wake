The bedside stop button is an ESP32 board (Heltec WiFi Kit 32 V1) that calls the
clock over Wi-Fi. **Nothing has to be wired**: the button and the screen are on
the board. You only power it.

## What is already on the board

| Function | Where | Pin |
|---|---|---|
| Stop button | `PRG` push-button | GPIO0 (pressed = low, internal pull-up) |
| Screen (SSD1306 128 × 64) | on board, I²C | SDA GPIO4 · SCL GPIO15 · RST GPIO16 |
| Reset | `RST` push-button | not usable by the application |
| Power and flashing | micro-USB | 5 V |

Set `ROBINE_WIFI_SSID`, `ROBINE_WIFI_PASSPHRASE` and, once paired,
`REMOTE_BUTTON_ID` and `REMOTE_BUTTON_SECRET_HEX` in `.env`, then:

```sh
make button-build
make button-upload PORT=/dev/ttyUSB0
make button-monitor PORT=/dev/ttyUSB0
```

## Optional: a bigger external push-button

To press something larger than `PRG` (for example through the enclosure), wire a
normally-open push-button **in parallel with `PRG`**: between GPIO0 and GND. No
resistor is needed, the firmware enables the internal pull-up.

To use another pin, change `STOP_BUTTON_PIN` in `hardware/remote_button/platformio.ini`.
The screen pins are fixed in the firmware for the Heltec V1; another ESP32 board
needs a code change.

## LoRa button

A radio version of the button (Arduino Pro Mini 3.3 V + RFM95) is described in
the [remote button note](../../notes/remote-alarm-button/). The wiring of the
**receiver** on the Pi is in [Wiring — Raspberry Pi 3](../wiring-pi3/#3-bedside-button--lora-module-sx1276--rfm95);
the button-side wiring is not documented yet.
