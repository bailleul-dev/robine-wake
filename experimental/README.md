# Experimental

> Ce sont des prototypes jetables. Ils ne sont pas compilés par `mix verify`,
> pas inclus dans le firmware Nerves, pas déployés dans la démo, pas couverts
> par la traçabilité des exigences. Ils peuvent être supprimés sans préavis.

|---|---|---|
| [`robine-wake-rs/`](robine-wake-rs/README.md) | Évaluation d'un port Rust de l'API locale, en vue d'un futur système Buildroot sur carte custom | prototype, décision non prise |

Nerves dans `nerves_system_rpi3/`. Voir la discussion d'évaluation résumée
dans le README du prototype.
